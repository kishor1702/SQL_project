# 45 Business Questions

## Beginner — Q1 to Q15
1. How many customers are there?
2. How many branches are there?
3. How many accounts are open?
4. What is the account-type distribution?
5. How many customers are in each risk band?
6. What is the transaction count/value by debit vs credit?
7. What is average transaction value by channel?
8. Which transaction types have the highest value?
9. Which customers belong to each home branch?
10. Which customers have no accounts?
11. Which branches have more than 300 customers?
12. How many accounts are open vs closed?
13. What are the highest-value individual transactions?
14. Which customers have no accounts using `NOT EXISTS`?
15. Which accounts have the highest total transaction value?

## Intermediate — Q16 to Q30
16. What are monthly credits, debits and net flow?
17. How does monthly transaction volume change?
18. What is each branch's customer/account footprint?
19. Which branches have the highest transaction value?
20. Which customers have the highest transaction activity?
21. What is each customer's credit, debit and net flow?
22. How should customers be segmented by value/activity?
23. Which customers are above the average customer transaction value?
24. Which open accounts have been inactive for 90+ days?
25. Which customers hold multiple accounts?
26. How many active customers are there each month?
27. Which transaction channels are used most?
28. How does transaction behavior vary by risk band?
29. Which account types generate the most transaction value?
30. Which branches outperform the bank-wide average?

## Advanced — Q31 to Q45
31. What is the reconstructed running balance for every account?
32. Which accounts went below zero?
33. What are each account's first and latest transactions?
34. How do branches rank by transaction value?
35. How do customers rank within their branches?
36. What is month-over-month change in net flow?
37. What is the cumulative bank-wide net flow?
38. Who are the top 3 customers in each branch?
39. How does monthly transaction value change by account type?
40. Which customers are Champions, Loyal, At Risk or Inactive?
41. What is the branch executive scorecard and bank contribution?
42. Which card payments look like possible duplicate charges?
43. What is the largest debit for each customer?
44. Which customers reduced transaction value in their latest month?
45. What is the final customer value ranking?
